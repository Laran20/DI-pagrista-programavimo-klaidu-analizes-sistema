# Išsaugoti tikri rezultatai

Šie JSON failai eksportuoti iš 2026-10-14 Colab užrašyne išsaugotų tikrų `gemini-3.5-flash-lite` atsakymų. Tai nėra naujai sugeneruoti ar etalonais pakeisti atsakymai. `export_source: saved_notebook_outputs` nurodo eksporto šaltinį. Originalios analizės išvestys ir grafikai palikti pagrindiniame `.ipynb`.

`summary.csv` pateikia trijų užklausų rezultatus. `verification.json` pateikia 7 atskiras lokalias patikras, atliktas peržiūrėtam modelio kodui. Jos nėra papildomos Gemini užklausos ir neįtraukiamos į API užklausų trukmes.
